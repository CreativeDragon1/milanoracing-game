Milano Racing

MR 26. Fourteen circuits. Qualifying, races, practice, time trial and online rooms.

Windows

Extract Milano-Apex-Windows.zip. Open Milano Apex.exe inside its folder. Keep the supporting files beside it. Solo play works offline. Use Online in the home screen for your private hosted multiplayer.

Browser

Open Milano Racing.html in Edge or Chrome. The assets are embedded. Bluetooth pairing is done in the operating system; then return to the game and press a controller button.

Ubuntu server

Use Milano-Racing-Server.zip. The Python server handles access and multiplayer; players' devices render the graphics. The supplied service remains private until configured otherwise.

Source build

Extract the Source ZIP. From its root, install Python 3.12+ and Pillow, then run:

python -m pip install Pillow
python upgrade/build-base.py
node --check upgrade/qa/game.js
python upgrade/build-web.py

The generated hosted game is upgrade/server/public; the embedded HTML is upgrade/qa/standalone.html. The build reads its own vendor folder, not the old Downloads copy. Optional geography/line regeneration additionally needs NumPy, SciPy, Numba and Shapely 2.1+, and the research data. Defaults use the checked-in processed circuit and tree assets.

For the independent desktop build, use the separate Milano-Racing-Native-Source.zip and its README. The older Electron wrapper remains an optional compatibility build. To package that wrapper, run python upgrade/tools/sync-desktop.py, then run npm ci --prefix upgrade/desktop and npm run package:win --prefix upgrade/desktop. Run npm ci --prefix upgrade for Playwright browser tests; they use installed Microsoft Edge. Run tests from the extracted source root, for example node upgrade/tests/weekend-core.cjs. Browser tests expect the local preview server on port 8878; the website integration check also expects the existing site on port 5173. The offline HTML test needs no server. See upgrade/tests/README.txt. The website patch is under upgrade/integration/website-files; merge it with the existing React site rather than replacing unrelated site work.

Deployment status: the packages are local deliverables. The source can be uploaded to the requested GitHub repository without deploying the game. No Cloudflare tunnel, DNS or live website deployment has been performed; private server access remains the default.
