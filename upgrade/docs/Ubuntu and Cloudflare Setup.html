MILANO RACING / SERVER GUIDE / 22 OCTOBER 2026

Your private test server.

Host the game on Ubuntu 24.04 LTS, manage it through SSH, and publish it at your own HTTPS address with Cloudflare Tunnel. The hosted game is password-protected by default. Once installed, both services start at boot and keep running when you close SSH.

Your address: https://game.milanoracing.team
The domain is set throughout this guide and in the supplied configuration. Replace only SERVER_IP and YOUR_USER with your server details.

Private testing: visitors can see only an access screen. The game HTML, graphics, sound and multiplayer endpoints require a signed access cookie after entering your password. With no password configured, the game stays locked. The standalone HTML in your Downloads folder is a separate offline copy; share it only with people you want to have the game.

The backend is Python. The Ubuntu edition uses one asynchronous aiohttp process. Graphics, sound and vehicle physics run in players’ browsers, so the server does not need a GPU or a desktop environment. Rooms support 2–16 drivers; races use ghosts rather than car-to-car collision physics.

1 / Find your server and domain

Get the server’s IP address, SSH username and password or private key from its owner or hosting dashboard. In Cloudflare, open the Websites list and select milanoracing.team. The domain must be active on your Cloudflare account. If it is registered elsewhere, follow Cloudflare’s domain-onboarding instructions before creating the public route.

Open PowerShell on your Windows computer. Replace the placeholders and connect:

ssh YOUR_USER@SERVER_IP

For a private key, use ssh -i "C:\path\to\your-key" YOUR_USER@SERVER_IP. On first connection, compare the server fingerprint with the hosting console before accepting it. Passwords are not displayed while typing.

In the Ubuntu SSH terminal, check the OS and available resources:

cat /etc/os-release
nproc
free -h
df -h /
uname -m

This package targets Ubuntu 24.04 and Python 3.12. It uses standard Python networking and works on amd64 or arm64 when dependencies are installed for that machine. The verification supplied with this build covers amd64 Ubuntu 24.04 under WSL. Allow space for the system, updates, game files and a previous release. Start with one event room and check actual CPU, memory and latency before increasing attendance; your remote server’s capacity has not been measured.

Keep the SSH terminal open. Open a second PowerShell window on Windows and upload the ZIP from Downloads:

scp "$env:USERPROFILE\Downloads\Milano-Racing-Server.zip" YOUR_USER@SERVER_IP:~/

Return to the Ubuntu SSH terminal:

sudo apt update
sudo apt install -y python3 python3-venv unzip curl ca-certificates rsync
mkdir -p "$HOME/milano-upload"
unzip -o "$HOME/Milano-Racing-Server.zip" -d "$HOME/milano-upload"
cd "$HOME/milano-upload/Milano-Racing-Server"
ls

You should see milano_server.py, race_core.py, requirements.txt, milano.service and a public directory. Upload this full package. The standalone HTML alone provides solo play but does not host multiplayer.

3 / Install the Python service

The game runs as a dedicated account, with read-only access to its installed files. Run these commands in Ubuntu from the extracted package folder:

id milano >/dev/null 2>&1 || sudo useradd --system --user-group --home-dir /opt/milano --shell /usr/sbin/nologin milano
sudo install -d -m 755 /opt/milano
sudo rsync -a --exclude='.venv' ./ /opt/milano/
sudo chown -R root:root /opt/milano
sudo chmod -R a+rX /opt/milano
sudo python3 -m venv /opt/milano/.venv
sudo /opt/milano/.venv/bin/pip install -r /opt/milano/requirements.txt
sudo install -m 600 /opt/milano/milano.env.example /etc/milano.env
sudo nano /etc/milano.env

Set your actual hostname. Keep the service on loopback:

PUBLIC_ORIGIN=https://game.milanoracing.team
BIND=127.0.0.1
PORT=8767
TRUST_CLOUDFLARE=1
PRIVATE_SITE=1
SITE_PASSWORD_HASH=
SESSION_SECRET=

Use just the HTTPS origin: no path, port or trailing slash. In nano, press Ctrl+O, Enter, then Ctrl+X. For an optional local preview before publishing, temporarily leave PUBLIC_ORIGIN= empty for local testing and set it before publishing.

Set a private test password now. The prompt hides your input, stores only a salted password hash, and creates a signing secret. Choose at least 12 characters and share it only with your testers:

sudo /opt/milano/.venv/bin/python /opt/milano/set-private-password.py

Do not change PRIVATE_SITE=1 while the game is in development. Without configured credentials, visitors remain locked out.

sudo install -m 644 /opt/milano/milano.service /etc/systemd/system/milano.service
sudo systemctl daemon-reload
sudo systemctl enable --now milano
sudo systemctl status milano --no-pager
curl -fsS http://127.0.0.1:8767/healthz

Expected health response: {"status": "ok"}. The service status should say active (running). It is normal that http://SERVER_IP:8767 is unreachable from another computer: the server intentionally listens only on loopback.

Optional preview before your domain is ready: with PUBLIC_ORIGIN= empty, open a separate Windows terminal and run ssh -L 8767:127.0.0.1:8767 YOUR_USER@SERVER_IP. Browse to http://localhost:8767. Keep that SSH session open while previewing. After setting the real origin, use the public hostname for multiplayer.

4 / Install and connect Cloudflare Tunnel

If this server already has a working Cloudflare Tunnel, reuse it: add the route in step 5 and skip the new connector installation below. Do not replace an existing tunnel or its credentials.

For a new connector, install Cloudflare’s stable package in Ubuntu:

sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null
echo 'deb [signed-by=/usr/share/keyrings/cloudflare-main.gpg] https://pkg.cloudflare.com/cloudflared any main' | sudo tee /etc/apt/sources.list.d/cloudflared.list
sudo apt update
sudo apt install -y cloudflared
cloudflared --version
command -v cloudflared

The package should install /usr/bin/cloudflared, which the supplied service uses. The token-file option requires version 2025.4.0 or newer.

  1. In your browser, sign in to Cloudflare and open Networking → Tunnels → Create Tunnel. Some accounts show this under Cloudflare One / Networks / Connectors.
  2. Name the tunnel milano-racing and choose the server’s operating system and architecture.
  3. Locate the connector token in the supplied install/run command. Copy only the long value after --token. We will store it in a protected file rather than put it into shell history.

In Ubuntu:

id cloudflared >/dev/null 2>&1 || sudo useradd --system --user-group --home-dir /nonexistent --shell /usr/sbin/nologin cloudflared
sudo install -d -o root -g cloudflared -m 750 /etc/cloudflared
sudo install -o root -g cloudflared -m 640 /dev/null /etc/cloudflared/milano-token
read -rsp 'Paste tunnel token, then press Enter: ' MILANO_TUNNEL_TOKEN
printf '\n'
printf '%s' "$MILANO_TUNNEL_TOKEN" | sudo tee /etc/cloudflared/milano-token >/dev/null
unset MILANO_TUNNEL_TOKEN
sudo install -m 644 /opt/milano/cloudflared-milano.service /etc/systemd/system/cloudflared-milano.service
sudo systemctl daemon-reload
sudo systemctl enable --now cloudflared-milano
sudo systemctl status cloudflared-milano --no-pager

The token will not appear while pasting. Keep it private. Do not include the token file in screenshots, archives or support messages. This custom unit is called cloudflared-milano; use that name in the commands below.

Return to the dashboard and wait for Healthy. The connector needs outbound access to Cloudflare on port 7844 (UDP for QUIC or TCP for HTTP/2), plus DNS. Package downloads use HTTPS. No inbound web-server port or router forwarding is required. Keep your existing SSH access rule; if enabling a firewall, allow your actual SSH port first and confirm a second SSH connection before closing the first.

5 / Publish your hostname

Open your tunnel’s Routes → Add route → Published application (older dashboards call this Public Hostname). Set:

FieldValue
Subdomaingame
Domainmilanoracing.team
PathLeave empty
Service typeHTTP
Service URLhttp://127.0.0.1:8767 (or 127.0.0.1:8767 when HTTP is selected separately)

Save the route. Cloudflare creates the DNS route for the chosen hostname. If that exact hostname already serves another site, use a different unused subdomain rather than replacing it.

Players connect over HTTPS to Cloudflare. The tunnel forwards to HTTP on the same server’s loopback interface; you do not need a self-signed origin certificate or a “no TLS verify” override. Leave the origin Host header unchanged.

Make sure PUBLIC_ORIGIN in /etc/milano.env exactly matches the new HTTPS address, then run sudo systemctl restart milano. This restart closes current rooms.

Private mode caching: authenticated assets use browser-only private caching; the access screen, game page and API use no-store. Do not add a Cloudflare rule that overrides these headers or forces edge caching.

Use Cloudflare’s normal caching defaults. If you have custom “cache everything” rules, exclude /api/* and /healthz and respect origin cache headers for HTML. The game marks multiplayer responses no-store, the HTML no-cache, and hashed assets as private/immutable during testing (public/immutable only after launch). Do not cache lobby responses or apply interactive challenges to every game API request.

6 / Check before the event

curl -fsS https://game.milanoracing.team/healthz
curl -I https://game.milanoracing.team/
sudo systemctl is-enabled milano cloudflared-milano
sudo systemctl is-active milano cloudflared-milano
  1. First open the HTTPS website in a private/incognito window. Confirm you see only Private testing, and that a direct /api/info visit is blocked. Then enter the test password.
  2. Open the HTTPS website in a current Chrome, Edge or Firefox browser. Load a circuit and drive a practice lap. The browser device needs hardware-accelerated WebGL.
  3. Press a button on the Bluetooth-paired controller after opening the page. Pairing happens in the player’s OS settings. The browser reads the controller through the Gamepad API; the server does not pair controllers.
  4. Open the website on a second device. Host a room, copy its invite, join it, ready both drivers and start. Confirm the circuit matches, both cars appear, and results arrive.
  5. Test on the actual venue network and speakers. Keep music/volume appropriate for the event. Browser audio starts after an interaction.
  6. Close SSH and verify the website remains online. When no race is running, test a server reboot and verify both services return automatically.

The first visit downloads the graphics and audio. Later visits can reuse cached assets without reducing texture resolution. Internet latency still affects multiplayer. Races are casual ghost sessions with basic server movement/checkpoint checks; this is not a competitive anti-cheat system.

Online race behavior

Drivers open the same HTTPS game, create or join a room, ready up, and race. An invite retains the room code through private login. Unlisted rooms are the default; the host can opt to show a room on the grid. Each room supports sixteen drivers. Equal setups and ghost opponents keep casual events manageable. WebSocket updates use interpolation and bounded prediction; HTTPS polling is a fallback. A disconnected driver has 30 seconds to reconnect before being marked DNF.

The host server owns countdown, checkpoints, penalties and results. Vehicle dynamics run locally. Geographic distance still adds latency; the tunnel does not eliminate it. Before an event, test two devices on different Internet connections through the real domain. Cloudflare can restart connections, so the client reconnects automatically. 7 / Keep it running

These units use automatic restart on process failure, restricted service accounts and rate-limited journal logging. The game has bounded room/player counts and removes old credentials. No database, build server, browser or GPU process is needed on Ubuntu. Use one Python process: multiple workers would have separate room lists.

sudo systemctl status milano cloudflared-milano --no-pager
sudo journalctl -u milano -n 60 --no-pager
sudo journalctl -u cloudflared-milano -n 60 --no-pager
sudo systemctl show milano -p MemoryCurrent -p CPUUsageNSec -p NRestarts
free -h
df -h /
journalctl --disk-usage

The Python unit has a 512 MB memory ceiling, not a reservation. Leave memory for Ubuntu, Cloudflare and other services. If monitoring shows the ceiling is genuinely too low, inspect the cause and adjust it deliberately rather than continually restarting. Ensure the physical host does not sleep; an Ubuntu VM stops serving when its host sleeps.

Rooms and results are held in memory. Restarting the game service ends active races; personal bests stay in each browser. Apply OS, Python dependency and cloudflared updates between sessions. A pinned dependency helps reproduce this build but should still receive reviewed security updates over time.

Manage private access

Each successful login lasts 12 hours. To revoke all current sessions and change the password, run:

sudo /opt/milano/.venv/bin/python /opt/milano/set-private-password.py
sudo systemctl restart milano

Keep /etc/milano.env private: it contains the password hash and cookie signing key. The gate limits password attempts and blocks direct asset/API requests. A shared password is suitable for a small trusted test group. Testers can still copy content they can access; do not distribute the offline HTML publicly. Cloudflare Access can add individual account-based access later if you need per-person revocation.

When you decide to launch publicly

Only when you are ready, edit /etc/milano.env, set PRIVATE_SITE=0, and restart milano. Keep the current value at 1 until then. To return to private mode, set it back to 1, restart and purge any Cloudflare cache for the hostname. Files already downloaded by visitors cannot be recalled.

Update the game safely

Upload and extract the new ZIP into a new folder first. When the grid is empty:

sudo systemctl stop milano
sudo cp -a /opt/milano "/opt/milano-backup-$(date +%Y%m%d-%H%M%S)"
sudo rsync -a --exclude='.venv' "$HOME/milano-upload/Milano-Racing-Server/" /opt/milano/
sudo chown -R root:root /opt/milano
sudo chmod -R a+rX /opt/milano
sudo /opt/milano/.venv/bin/pip install -r /opt/milano/requirements.txt
sudo install -m 644 /opt/milano/milano.service /etc/systemd/system/milano.service
sudo systemctl daemon-reload
sudo systemctl start milano
curl -fsS http://127.0.0.1:8767/healthz

The configuration in /etc/milano.env and tunnel token remain outside the release. Retaining old hashed assets lets existing browser sessions finish loading. Keep one known-good backup; remove older backups manually once the new release has been verified and no rollback is needed. To roll back, stop the service, copy files from that known-good backup to /opt/milano, reinstall its requirements, and start it again.

Troubleshooting

SymptomCheck
SSH times outCorrect IP, username, actual SSH port and provider firewall. Use the provider’s console if locked out.
“externally managed environment” from pipUse /opt/milano/.venv/bin/pip, not the system pip.
Cloudflare 502Check the local health URL and milano service. The route must use HTTP on 127.0.0.1:8767.
Tunnel disconnected / 1033Check cloudflared-milano, token permissions, DNS and outbound 7844. If UDP is blocked, Cloudflare can use HTTP/2 over TCP.
“Open the game at this server address”Match PUBLIC_ORIGIN to the browser’s HTTPS origin and restart the game service.
Room cannot be joinedBoth devices need the same public server. Check the six-character code, sixteen-player limit and whether the race has started.
429 / too many requestsWait briefly, close duplicate tabs and investigate automated traffic. Sixteen normal players behind one Wi-Fi connection are accommodated by the configured limits.
Controller missingUse HTTPS or localhost, pair it in the OS, press a controller button and focus the game tab. Browser and controller mappings can differ.
Low frame rateCheck the playing device’s hardware acceleration and GPU. The server does not render frames. Try the game’s Performance option on weaker clients.
No soundClick into the game, check engine volume, the browser’s site mute setting and the OS output device.

For support, share service status and recent error messages with tokens and personal addresses removed. Do not send private keys or the contents of milano-token.
