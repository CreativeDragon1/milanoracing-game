MILANO RACING · ENVIRONMENT RESEARCH · 23 OCTOBER 2026

Whole-circuit surroundings

This is the environment inventory for all twelve circuits. The acceptance target is a continuous, recognisable setting throughout a lap: distinctive buildings, supporting neighbourhoods, terrain, vegetation, roads, bridges, shorelines, grandstands and pits. One landmark per track is not sufficient.

Evidence status: geographic footprints and source IDs establish placement, not facade fidelity. Architectural meshes are reconstructions. A count of buildings or a successful load test does not prove a complete replica. The remaining accuracy work below is deliberately visible.

How the environment is built

  1. Register OSM footprints and roads to each circuit’s metre coordinate frame; retain source way/node IDs.
  2. Use terrain elevation and mapped land cover for foundations, slopes, shorelines and forests. Satellite colour is from 2016/2017 and is not evidence of current building geometry.
  3. Reconstruct important silhouettes and structural features from promoter, architect, fabricator and heritage sources. Detailed dimensions without a published reference remain estimates.
  4. Check concave roofs/courtyards, bridge continuity and supports, road clearance and full-lap views. Keep moving guides and foliage out of immutable scenery batches.
  5. Measure render cost with repeatable viewpoints and keep the same scene across quality presets. Do not substitute a landmark count for visual inspection.

Partner presentation

All six supplied partners receive the same total wall-wrap length per circuit. Prominent gantries rotate across the calendar; each partner receives eight gantry faces and ten modelled pit-facade panels. Stand fascias rotate through all six marks. Sponsor graphics use the supplied artwork and attach to track infrastructure; these are fictional Milano event placements, not claims of real venue sponsorship.

Remaining fidelity work

These are game reconstructions, not laser scans. Individual facade proportions, ornament, roof plant, vegetation species and temporary race furniture still need reference matching. Facade detail, exact temporary seating and season-specific installations remain approximate across the calendar. Coarse terrain, vegetation species, ride profiles and historic overpass junctions require further site-specific data. Public OSM data has missing heights and incomplete outlines; generic geometry at those locations must not be presented as verified architecture.

Source trail and reproducibility

Read src/venue-context-data.json for each selected name, footprint, original tags, source URL, courtyard holes and roof mesh. qa/venue-source-inventory.json lists named structures in the cached extracts. tools/venue-context.py rebuilds selections and roof geometry offline; it requires Shapely 2.1 or later. The normal game build only reads the baked JSON. OSM-derived data remains attributed under ODbL; reference photographs and promoter PDFs are not redistributed in the release.
